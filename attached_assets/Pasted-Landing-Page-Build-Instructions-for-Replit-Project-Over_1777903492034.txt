Landing Page Build Instructions for Replit

Project Overview
Build a high-converting VSL landing page for a done-for-you cold email & LinkedIn outreach agency. The page must be optimized for cold traffic B2B prospects (coaches, consultants, service providers) and designed to maximize qualified call bookings.

---

Technical Requirements

Tech Stack
• Framework: Next.js 14+ with App Router
• Styling: Tailwind CSS
• Video Player: Vimeo or custom HTML5 player (NOT YouTube • no distractions)
• Form: Simple calendar booking integration (Calendly embed or custom form)
• Hosting: Vercel (for easy deployment from Replit)

Performance Requirements
• Page load time under 2 seconds
• Mobile-responsive (50%+ of traffic will be mobile)
• No unnecessary animations or distractions
• Clean, professional design (not flashy)

Design System

Colors
• Primary: 2563EB (blue) or DC2626 (red)
• Success: 10B981 (green)
• Background: FFFFFF (white), F9FAFB (light gray)
• Text: 111827 (dark), 6B7280 (medium gray), 9CA3AF (light gray)
• Borders: E5E7EB

Typography
• Font Family: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
• Headings: Bold weight
• Body: Regular weight
• Line Height: 1.5 for body text, 1.2 for headings

Spacing
• Section Padding: 80px top/bottom (desktop), 48px (mobile)
• Element Spacing: 16px, 24px, 32px, 48px (use multiples of 8)

Buttons
• Primary: Bold background color, white text, 16px-18px font size
• Hover: Slightly darker shade (10-20% darker)
• Padding: 16px 32px
• Border-radius: 8px

Cards
• Background: White
• Border-radius: 12px
• Box-shadow: 0 4px 12px rgba(0,0,0,0.08)
• Padding: 32px

---

Mobile Responsiveness

Breakpoints
• Desktop: 1024px+
• Tablet: 768px • 1023px
• Mobile: 0px • 767px

Mobile Adjustments
• Reduce font sizes by 20-30%
• Stack columns vertically
• Reduce padding (80px → 48px)
• Increase button size for touch targets (min 44px height)
• Simplify navigation (hamburger menu if needed)

Form/Calendar Integration

Option 1: Calendly Embed
```html
<!-- Calendly inline widget begin -->
<div class="calendly-inline-widget" data-url="https://calendly.com/your-link" style="min-width:320px;height:700px;"></div>
<script type="text/javascript" src="https://assets.calendly.com/assets/external/widget.js" async></script>
<!-- Calendly inline widget end -->
```

Option 2: Custom Form
If using a custom form, collect:
• Name (required)
• Email (required)
• Phone (optional)
• Company/Business Name (optional)
• "What's your biggest challenge with lead generation?" (optional text area)

Form Styling:
• Input fields: 16px font, 48px height, 12px padding, E5E7EB border
• Submit button: Same as primary CTA button
• Validation: Red error messages below fields

---

Additional Notes

What NOT to Include
• No navigation menu (single-page VSL landing page)
• No footer links to other pages (keep them on this page)
• No social media icons (distracting)
• No live chat widget (distracting)
• No pop-ups or exit-intent modals (annoying)

What TO Include
• Smooth scroll to CTA buttons
• Sticky CTA button on mobile (optional)
• Fast page load (optimize images, lazy load video)
• Clean, professional design (not flashy or "salesy")
