## 2. Design system

### Color tokens (define once, e.g. in `tailwind.config` theme)
| Token | Hex | Role |
|---|---|---|
| `cream` | `#F4EFE3` | Page base |
| `cream-2` | `#EFE8D8` | Alt section background |
| `ink` | `#0B0D12` | Primary text + dark sections |
| `ink-2` | `#11131B` | Dark cards |
| `ink-soft` | `#54596A` | Secondary text |
| `line` | `rgba(11,13,18,.12)` | Borders/dividers |
| `accent` | `#1466FF` | Electric blue — buttons, highlights, links |
| `accent-deep` | `#0B49C9` | Hover / deeper blue |
| `green` | `#34d399` | Positive / recovered states (tracker) |
| `orange` | `#f97316` | "Leak" indicators (profit diagram) |

This is a **light/cream** design with heavy black ink and ONE loud accent (the brand blue pulled from the logo). Dark (`ink`) and full-blue (`accent`) sections are used for contrast/rhythm.

### Typography (Google Fonts)
- **Display / headlines:** `Anton` — uppercase, `letter-spacing: .004–.006em`, `line-height: 1.05–1.09`. Used for all H1/H2, big stat numbers, step numbers.
- **Body / UI:** `Hanken Grotesk` (weights 400–800). NOT Inter.
- **Signature accent:** `Caveat` (handwriting) — used only for Ryne's signature on the guarantee card.
- Key sizes: hero H1 `48px`; section H2 `58px` (`.sm` = `46px`); lead `20px`; body `15–18px`; eyebrow `12–13px` uppercase tracked.
- Import: `Hanken+Grotesk:wght@400;500;600;700;800&family=Anton&family=Caveat:wght@600;700`

### Logo / wordmark (rebuilt in type — see `brand.jsx`)
Flask SVG mark (accent-blue Erlenmeyer + 3 circuit nodes) + wordmark: **JOBS** (ink) **DONE** (accent), italic 800, with a small `— LABS —` lockup (letter-spaced, flanked by hairline rules) beneath. Renders crisp on cream; no raster logo needed. A dark-background version flips JOBS to cream.

### Spacing / shape
- Section vertical padding ~`104–112px`; container `max-width: 1200px` (hero `1290px`), side padding `56px`.
- Radii: cards `16–28px`, pills/buttons `11–16px` (pills `100px`).
- Buttons: solid accent fill, white text, weight 800, subtle blue drop-glow; sizes sm/lg/xl. Ghost variant = transparent w/ ink ring.

## 4. Interactions (must-keep behavior)

- **Booking modal** → opens on EVERY CTA. Implementation: a global click handler intercepts `a[href="#book"]`, opens a modal containing a Calendly iframe `https://calendly.com/ryne-bandolik` (params: `hide_gdpr_banner=1&background_color=0b0d12&text_color=f4efe3&primary_color=1466ff`). Closes on ×, overlay click, or Escape; locks body scroll. Sub-page "Book a Call" buttons just link to Calendly in a new tab. **Re-add your Meta Pixel `Schedule` event on modal open.**
- **VSL** → YouTube ID `FP_yxHX9Zvc`. Autoplays **muted** on load (`autoplay=1&mute=1`); a caption pill "🔊 Watch the 4-min breakdown · Tap for sound" overlays the video and, on tap, reloads the iframe unmuted (`mute=0`).
- **Industry marquee** → CSS `translateX` loop (duplicated track, `-50% - halfgap`), `animation-play-state: paused` on hover, disabled under `prefers-reduced-motion`.
- **FAQ accordion** → single open item, animated max-height, `+`→`×` icon rotate.
- **ROI calculator** → 5 range sliders (annual revenue, leads/mo, deal value, % leads lost to slow follow-up, admin hrs/wk) drive a live estimate. Formula (see `roi-calculator.html`): recovered leads = `lostDeals × 0.40 × 0.30 × dealValue`; reclaimed time = `hrs × 0.55 × $45 × 50wks`; efficiency = `revenue × 0.011`; total floored at $30K. Slider fill tinted by value.

## 7. Porting notes for the Replit agent
- Move the CSS custom-property tokens (Section 2) into `tailwind.config` `theme.extend.colors` + `fontFamily`; you can keep your existing inline-style pattern or convert the provided classes — both map cleanly.
- Each landing section in `lp-parts*.jsx` is a self-contained component — recreate as TSX components with the same DOM structure and class names, then attach the styles from `page.css`/`styles.css`.
- Replace the Babel/CDN React with your normal TSX. The booking modal + VSL state map directly to `useState`/`useEffect`.
- Animations (Framer Motion in your current build) are optional sugar — the reference uses CSS only; add scroll fade-ups back if you want.
